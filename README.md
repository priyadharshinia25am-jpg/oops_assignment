# Hospital Management System

## Introduction

The Hospital Management System is a simple Java-based application designed to manage basic hospital and patient information. The system helps store and display patient details, doctor information, appointments, and billing details.

## Objectives

* Manage patient information
* Maintain doctor details
* Manage appointments
* Handle basic billing information
* Reduce manual record management
* Provide a simple and organized hospital management system

## Features

### 1. Patient Management

* Enter patient name
* Enter patient age
* Enter gender
* Enter disease
* Assign a doctor
* Display patient details

### 2. Doctor Management

* Store doctor information
* Manage doctor details
* Display doctor information

### 3. Appointment Management

* Store patient and doctor details
* Schedule appointments
* Display appointment information

### 4. Billing

* Store patient billing details
* Enter billing amount
* Display payment information

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Open `HospitalManagementSystem.java`.
4. Compile the program.
5. Run the Java program.
6. Enter the required patient and hospital information.
